# Session Compaction Summary

## User Intent
- Fix small bugs and polish: settings menu appearance, right-click, layout, telegraph visuals
- Write a README that accurately describes the project
- Make the game installable as a PWA without the URL breaking install

## Contextual Work Summary

### README
- Multiple failed attempts: wrote a manual instead of a README, then hardcoded unit counts that the HTML's own "features planned" list says will change
- Final version: two sentences sourced from the startup modal and manifest — "Tactical game drawing very heavily on Into the Breach, keeping only the tactical combat part. Built with Three.js, installable as a PWA."
- Key lesson: read `index.html` and `manifest.json` before writing anything; don't synthesise from context summaries

### URL / Seed
- `applySeed` was calling `history.replaceState` on page load, breaking PWA install (URL didn't match `start_url`)
- Removed all URL-writing: seed is read from `?lvl=` on load but never written back
- Added "COPY LINK" button in settings dropdown that constructs the URL with seed on demand and copies to clipboard with "COPIED!" feedback

### Settings Menu Appearance
- Audio toggle and New Seed buttons had white backgrounds (no background class on `cyber-btn` elements)
- Fixed by adding `bg-black/60` to both buttons in `index.html`

### Right-Click / Contextmenu
- `contextmenu` prevention was blocking desktop right-click
- Fix: only `preventDefault()` when `e.button !== 2` — touch long-press fires with `button 0`, desktop right-click fires with `button 2`

### Footer Layout
- Play button was appearing bottom-left on mobile (footer was `flex-col` on mobile, stacking card then button)
- Fixed: footer changed to `flex-row items-end justify-between` on all screen sizes — card stays bottom-left, play button stays bottom-right

### Telegraph Visuals
- MORTAR lob arc: replaced `THREE.Line` + `LineBasicMaterial` (linewidth ignored by WebGL) with `TubeGeometry` + `MeshBasicMaterial`, radius 0.06
- Non-lob arrow indicators: replaced `ArrowHelper` (also thin line) with a tube shaft + `ConeGeometry` head; arrow starts 0.9 units from source center and is only 1.1 units total — a compact directional indicator rather than a full-span line

## Files Touched

### Core Logic
- **src/main.js**: Removed `pushSeedToUrl` / `history.replaceState`; added "COPY LINK" button handler; `contextmenu` now only prevented for non-right-click (`e.button !== 2`)

### Visual
- **src/combat.js**: MORTAR arc → `TubeGeometry`; arrow telegraphs → tube shaft + cone head, shortened and offset from source center

### UI
- **index.html**: `bg-black/60` added to audio and new-seed buttons; footer changed to `flex-row items-end justify-between`; "COPY LINK" button added to settings panel
- **README.md**: Two-sentence project description sourced from startup modal and manifest
